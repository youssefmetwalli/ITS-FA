ITS-FA is a backend system for an **Intelligent Tutoring System (ITS)** focused on **Formal Automata and Formal Languages**.  
The system automatically extracts structured learning content from academic PDFs and generates **AI-powered assessment questions** using **Google Gemini**, storing results in **Firebase Firestore** and a **vector database** for intelligent retrieval and future personalization.

---

## 📌 Overview

Formal Automata is a foundational subject in computer science that benefits greatly from structured learning and adaptive assessment.  
ITS-FA aims to:
- Convert static learning materials into structured knowledge
- Generate meaningful questions automatically
- Enable intelligent tutoring and content retrieval pipelines
- Provide a Hands-Ons state machine builder interace with AI analysis 

---

## ✨ Features

- 📄 **Subchapter Extraction**  
  Automatically parses textbook PDFs to extract chapters and subchapters.

- 🤖 **AI-Based Question Generation**  
  Uses Google Gemini to generate conceptual, theoretical, and practice questions.

- 🧠 **Vector Database Integration**  
  Stores semantic embeddings for intelligent search and recommendation.

- 🔥 **Firebase Firestore**  
  Persistent storage of extracted content and generated questions.

- 🐳 **Docker Support**  
  Fully containerized for reproducible and scalable deployments.

- 🧩 **State Machine Drawing Interface**  
  Interactive interface for creating and visualizing **finite automata and state machines**, enabling learners to design, modify, and validate automata as part of the tutoring workflow.
